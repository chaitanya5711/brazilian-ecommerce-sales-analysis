# 🇧🇷 Brazilian E-Commerce Sales & Customer Analytics

## 📊 End-to-End Data Analytics Project using Python, MySQL & Power BI

An end-to-end data analytics project analyzing the **Brazilian E-Commerce Public Dataset by Olist**.

The project transforms raw e-commerce data into actionable business insights using **Python for data cleaning and exploratory analysis, MySQL for business-focused SQL analysis, and Power BI for interactive visualization and dashboard development**.

---

## 🚀 Project Overview

E-commerce businesses generate large amounts of data across orders, customers, products, sellers, payments, reviews, and delivery operations.

This project analyzes approximately **100K+ orders and 112K+ order items** to understand:

- Sales and revenue performance
- Customer purchasing behavior
- Product category performance
- Customer geographic distribution
- Seller performance
- Delivery performance
- Freight costs
- Customer satisfaction
- Product and order trends

The final outcome is an interactive **Power BI dashboard** supported by Python-based data preparation and MySQL business analysis.

---

## 🎯 Business Objectives

The main objectives of this project were to answer important business questions such as:

1. What is the overall revenue generated?
2. How many orders and customers are present?
3. What is the average order value?
4. How does revenue change over time?
5. Which product categories generate the highest revenue?
6. Which customer states contribute the most revenue?
7. Which sellers generate the highest sales?
8. What percentage of orders are delivered on time?
9. How long does an average order take to reach customers?
10. What is the distribution of customer review scores?
11. How significant are freight costs compared with product revenue?
12. What percentage of customers are repeat customers?
13. Which products generate the highest revenue and sales volume?

# 📂 Dataset

The project uses the **Brazilian E-Commerce Public Dataset by Olist**.

The original dataset contains multiple relational tables covering:

- Orders
- Customers
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Geolocation
- Product Category Translation

The dataset covers Brazilian e-commerce transactions from approximately **2016 to 2018**.
